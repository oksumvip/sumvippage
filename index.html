关于 NetSpeed Pro

NetSpeed Pro 是一个开源、免费、无追踪的网络测速工具。

特点：

  • ✅ 纯 HTML/CSS/JS，无需服务器
  • ✅ 所有测速在本地完成，保护隐私
  • ✅ 使用全球 CDN 测速源（Cachefly）
  • ✅ 响应式设计，支持手机与电脑

项目可托管于 GitHub Pages、Vercel、Netlify 等平台，一键部署。
